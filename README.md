# Tarefa 2 – Algoritmos e Estrutura de Dados

Exercícios em Java sobre Listas (ArrayList), Pilhas, Filas, Maps (HashMap) e Algoritmos de Ordenação.
Cada exercício é uma classe independente, com seu próprio método `main`, dentro da pasta `src/`.

| Nº | Arquivo | Assunto |
|----|---------|---------|
| 1 | `Ex01_InversaoDeLista.java` | ArrayList – inversão manual, sem métodos prontos (menu interativo) |
| 2 | `Ex02_RemoverDuplicados.java` | ArrayList – remoção de contatos duplicados |
| 3 | `Ex03_MesclarListas.java` | ArrayList – intercalar duas listas de convidados |
| 4 | `Ex04_VerificacaoDeExpressoes.java` | Pilha – verificar parênteses balanceados |
| 5 | `Ex05_InversaoComPilha.java` | Pilha – inverter lista de produtos |
| 6 | `Ex06_FilaDeEspera.java` | Fila – fila de pacientes da clínica (menu interativo) |
| 7 | `Ex07_OrdemDeChegada.java` | Fila – ordem de chegada e saída de clientes |
| 8 | `Ex08_ContagemDePalavras.java` | HashMap – frequência de palavras |
| 9 | `Ex09_MesclarMapas.java` | HashMap – mesclar inventários tratando conflitos (soma as quantidades) |
| 10 | `Ex10_OrdenacaoPorVendas.java` | Quick Sort – produtos mais vendidos em ordem decrescente |

## Como executar

Pelo terminal, dentro da pasta do projeto:

```
javac -encoding UTF-8 -d bin src/*.java
java -cp bin Ex01_InversaoDeLista
```

Troque `Ex01_InversaoDeLista` pelo nome da classe do exercício desejado.
Também é possível abrir a pasta `src` em qualquer IDE (IntelliJ, Eclipse, VS Code) e executar cada arquivo.
